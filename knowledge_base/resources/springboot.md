# Spring Boot（后端开发）提升清单

## 适用岗位
- Java 后端开发
- 微服务开发

## 核心能力
- MVC/REST API 设计
- 数据访问（JPA/MyBatis）
- 鉴权（JWT/OAuth2）
- 配置与环境（profiles、config）
- 工程能力：日志、异常、参数校验、单元测试

## 可展示实践
- 从 0 搭建一个业务小系统（如：课程管理/招聘系统/问卷系统）
- 要求：接口文档、单测、日志、部署脚本
