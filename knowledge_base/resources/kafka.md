# Kafka（消息队列）学习路线

## 适用岗位
- 后端开发（Java/Python/Go）
- 大数据/数据平台
- 中间件/基础架构

## 核心知识点
1. 基本概念：Topic、Partition、Replica、Consumer Group
2. 消息语义：至少一次/至多一次/恰好一次（幂等 + 事务）
3. 性能调优：批量、压缩、ack、ISR、rebalance
4. 运维：监控、扩容、故障排查

## 最小可展示实践（简历可写）
- 使用 Kafka 完成“订单/日志”异步处理 Demo
- 至少包含：生产者、消费者、重试/死信、监控指标（lag）

- 1 篇学习总结（概念图 + 关键参数）
- 1 个可运行 Demo（README + Docker Compose）
- 1 份面试 Q&A（10~20 题）
